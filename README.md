## ◈ My approach to engineering

- **Understand first** — trace the business flow before changing code.
- **Build for failure** — plan for timeouts, retries, duplicate events and partial failures.
- **Make it observable** — use meaningful logs, correlation IDs and actionable monitoring.
- **Protect production** — validate changes, communicate impact and verify recovery.
- **Share what I learn** — create practical examples and open-source tools that others can use.
